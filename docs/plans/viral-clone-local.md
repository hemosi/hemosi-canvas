# 爆款复刻计划（本地优先版）

拍板：hemosi（2026-11-13）。替代《爆款复刻功能集成计划书（HemosiTV × Hypit）》。

## 和原计划书的区别

- **不调付费 API。** 分析全在本机：切镜头在浏览器里做，语音转写和看图理解走「OpenAI 兼容接口」，默认指向本机服务（Ollama 等）。以后真有 Key，只要在渠道里换个地址，代码不用改，这就是「同接口」。
- **不接 Hypit。** 它的复刻要靠 Claude Code / Codex 这类编程 Agent 写 SVML，还推荐付费聚合渠道，路线 B 整段砍掉。
- **没有任何模型也能用。** 只靠切镜头就能出蓝图：每个镜头一段，台词、画面描述你自己填。模型只是帮你少打字。
- 去掉费用预估、分析确认卡：本地不花钱，没什么可确认的。

## 动线

1. 在画布上选中一个视频节点，点工具栏「爆款复刻」（或让 Agent 打开）。
2. 弹窗第一步「拆解」：
   - 切镜头：浏览器内逐帧比对，必做，不联网。
   - 语音转写（可不选）：选一个转写模型，把视频的声音转成带时间的台词。
   - 看画面（可不选）：选一个能看图的模型，每个镜头送 1 张中间帧，让它写画面描述、景别、运镜、这段在整条视频里的作用（钩子/铺垫/转折/行动号召）。
   - 每一步可单独跳过；失败就显示原文报错，已完成的步骤保留。
3. 第二步「蓝图」：一张表，一行一个镜头：时间、作用、台词、画面描述、生成提示词，全都能改。上面是整条视频的钩子、风格一句话。
4. 第三步「替换与变体」：变量就是 `{{名字}}` 占位符（比如 `{{主角}}`、`{{产品}}`），在表里任何格子都能写；下面是变体表，一行一个变体，每列一个变量的值。
5. 「展开到画布」：每个变体生成一个分组：一个台词稿文本节点 + 一排分镜节点（描述、提示词、时长都填好）。不连源视频：只学结构，不把原片当生成参考。再展开一次就新建一组，不覆盖旧的。
6. 「导出素材包」：zip 里有 `blueprint.json`、`captions.srt`（按新台词在原镜头时长内均分，标明是草稿）、`shots.csv`、`README.txt`。

## 本机怎么配（推荐，按你 8G 显卡一次只开一个模型）

- 看画面：Ollama + `qwen2.5vl:7b`（约 6GB）。设置 → 模型渠道 → 添加渠道：协议 OpenAI，地址 `http://127.0.0.1:11434`，Key 留空，模型能力选「文本」。
- 语音转写：任何提供 `/v1/audio/transcriptions` 的本地服务，比如 speaches（faster-whisper）。渠道协议 OpenAI，地址填它的端口，Key 留空，模型能力选「音频」。
- 先跑转写再跑看图：两步是顺序执行的，中间可以关掉转写服务再开 Ollama。
- 都不想开：两个都不选，只切镜头。

## 不做（这一版）

- 平台链接下载（抖音/小红书链接），只认画布里的视频节点。
- 词级时间戳精确对字幕：替换后台词变了，原时间戳本来就对不上。
- 自动批量生成：展开后分镜照常用画布的批量生成，走原来的确认卡。
- 把源视频的人脸当参考图：默认不用，只学结构。

## 需要你拍板的边界值

## 验收

1. 不配任何模型：选中视频节点 → 爆款复刻 → 只勾切镜头，得到蓝图表，镜头数与画面切换对得上。
2. 配本地 Ollama（不填 Key）：看画面跑完，每行有画面描述和作用；关掉 Ollama 再跑，显示原文报错，切镜头结果还在。
3. 在两行台词里写 `{{主角}}`，变体表加 2 行，展开后画布多出 2 个分组，各自的台词和提示词带上各自的值，没有残留的 `{{`。
4. 导出 zip，用剪映导入 `captions.srt` 能看到字幕。
5. 关掉重开画布，蓝图还在。
