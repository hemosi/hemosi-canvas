## 一句话

Agent 就是画布右边一个聊天框：你说话，它读画布、动手改画布；每一笔改动先给你看清单，你点「应用」才落到画布，点「撤销」就退回去；花钱的生成一律再走原来的生成确认卡。

## 旧版为什么废

- 写死：内置「废土余烬」固定剧本，工具栏按钮一点就载入这个预设。
- 造假：没配视频 Key 时，用 `setTimeout` 假装生成，候选的验片项全部写死成「通过」，切点数直接照抄清单。
- 指令靠正则猜「第 N 段」，把你的话直接拼到提示词末尾。
- 界面：状态条 + 导演组 + 段矩阵 + 抽屉 + 页签，1700 多行的浮层，概念多、看不懂。

## 新 Agent 怎么工作

1. 你在聊天框说一句话（可勾「只看选中」）。
2. Agent 回复固定格式的 JSON：`say`（对你说的话）+ `calls`（要调的工具）。不用各家的 function calling，任何 OpenAI 兼容模型都能跑，本地 Ollama、DeepSeek、Gemini 代理都行。
3. 只读工具（读画布、读节点）自动执行，结果喂回模型，它接着想。
4. 改画布的工具攒成一张「改动卡」，列出每一步做什么。你点「应用」才执行，点「不要」它会收到「用户拒绝」再想别的办法。
5. 生成图片/视频的工具：分镜走批量生成（一张确认卡），其他节点逐个弹确认卡。Agent 自己永远不能跳过确认卡。
6. 每次应用后的结果（新建了哪些节点 id）喂回模型，它可以继续下一步，直到它说做完。

## 工具清单（第一版就这些）

| 工具 | 做什么 | 要不要你点 |
| --- | --- | --- |
| `read_canvas` | 读整张画布或选中部分的摘要 | 不用 |
| `read_node` | 读一个节点的完整内容 | 不用 |
| `add_text` | 新建文本节点（剧本、台词稿） | 改动卡 |
| `add_shots` | 新建一组分镜（带描述、提示词、时长） | 改动卡 |
| `add_anchor` | 新建角色/场景/风格锚点，可连到分镜 | 改动卡 |
| `update_node` | 改已有节点的标题、提示词、描述、文字、时长、比例 | 改动卡 |
| `connect` | 连线 | 改动卡 |
| `delete_nodes` | 删节点 | 改动卡（红色标出） |
| `generate` | 生成图片/视频 | 改动卡 + 生成确认卡 |
| `open_clone` | 对某个视频节点打开「爆款复刻」 | 改动卡 |

## 界面

- 顶部一行：思考模型选择、「只看选中」、清空对话。
- 中间：对话气泡。Agent 的工具调用折叠成一行小字（「读了画布：12 个节点」）。改动卡是一张带「应用 / 不要」的卡，应用后变成「已应用 · 撤销」。
- 底部：输入框，回车发送，Shift+回车换行，运行中显示「停止」。
- 不再有状态条、导演组、段矩阵、页签。

## 存储

- 对话按画布分开存，用 `localforage`，键 `agent:thread:<projectId>`。
- 不存图片和 base64，只存文字和节点 id。

## 验收（不看自述）

1. 不配任何模型：点发送，提示「先选思考模型」，不报控制台错。
2. 配一个本地 Ollama 文本模型（不填 Key）：说「把选中的文本拆成 4 个分镜」，出改动卡，应用后画布出现 1 个分组 + 4 个分镜，再点撤销全部消失。
3. 说「给这几个分镜出图」：弹出原来的生成确认卡，取消则零请求。
4. 换一张画布，对话是空的；切回来，对话还在。
5. 全文搜索代码里不再有「废土」「Wasteland」「setTimeout(r, 450)」。
