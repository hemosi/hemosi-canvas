# Muse 短剧视频提示词引擎（muse-drama-video）

本技能专为 **Muse（`muse-video` / HemosiTV 画布视频节点）** 打造。100% 沿用经实测跑通、彻底解决「大饼脸」与「AI 塑料味」的《Muse 10秒真人视频提示词底板》句式与结构，并将其从「单人写真摆拍」升维为支持**「单人剧情、双人对手戏、无角色纯空镜、不露脸道具局部特写」**四大短剧镜头的动态组装引擎。

---

## 一、核心铁律（直接写视频提示词，严禁写文档！）

1. **只写一段连贯具体的视频画面提示词，严禁任何文档格式**：
   - 绝对禁止写 `一、人物 / 二、站位 / 三、场景 / 四、镜头叙事 / 规则： / 负面排除：` 等标题、编号、项目符号（`•`）或说明文档！
   - 视频提示词就是直接喂给视频生成模型的一段**纯画面与动作描述**。
2. **模型看不到图片文件名或编号，必须靠「描绘图片里的画面长相」让模型认出是哪张参考图**：
   - 传给视频模型后，`@图5 / @图30 / 图1 / 图2 / CH01 / 角色A` 这些名字和编号模型统统看不到、也分不清！
   - 要让模型找到对应的参考图，必须在描述主体时**直接写出那张参考图长什么样**：
     - 例：用 `扎低马尾、穿深棕短款皮夹克和黑短裤长靴的女孩（五官和衣服与白底横版女孩三视图一致）` 代替 `@图5 / 角色A / 女主`；
     - 例：用 `留络腮胡、穿红棕无袖皮马甲和深色长裤的壮汉（五官和衣服与白底横版壮汉三视图一致）` 代替 `@图6 / 角色B / 疤爷`；
     - 例：用 `两端黄铜包裹、中间亮蓝光的玻璃圆筒管（外观与白底蓝光圆筒道具图一致）` 代替 `@图8 / P01`。
3. **严禁抽象词汇，只写肉眼可见的具体肢体动作与镜头运动**：
   - 绝对禁止写 `压低重心戒备、跨步逼近、神情冷冽、侧面交锋对峙、左右不颠倒、极具压迫感` 这种抽象小说词（视频模型根本听不懂什么叫“戒备”或“交锋对峙”）！
   - 必须拆成最直白的具体身体部位怎么动、镜头怎么动：
     - **谁在哪**：`画面左边站着…，画面右边半蹲着…，右手握着…`
     - **怎么动**：`往前迈出一大步，弯腰伸出右手去抓她手里的蓝光玻璃管`、`把蓝光玻璃管收到胸前，身体往右边退开一步躲过他的手，抬起左手挡开他的手腕`
     - **镜头怎么拍**：`镜头从正面中景缓慢往前推，跟着女孩后退顺势摇到两人近景侧面，女孩转过侧脸盯着壮汉，胸口起伏喘气，风吹动马尾碎发`

## 二、标准视频提示词范例（直接输出这种纯画面段落）

### 范例 1：双人争抢道具（带首帧 + 2张白底角色三视图 + 1张白底道具图）
```text
夕阳下的破旧废土加油站前，画面左边站着留络腮胡、穿红棕无袖皮马甲和深色工装裤的壮汉（脸部和衣服与白底横版壮汉三视图一致），画面右边半蹲着扎低马尾、穿深棕短款皮夹克和黑色短裤长靴的女孩（脸部和衣服与白底横版女孩三视图一致），女孩右手握着两端黄铜包裹、中间亮着蓝光的玻璃圆筒管（与白底蓝光玻璃圆筒图一致）。镜头从正面中景缓慢往前推进，左边的络腮胡壮汉往前迈出一大步，弯腰伸出右手去抓女孩手里的蓝光玻璃管；右边的皮衣女孩迅速把蓝光玻璃管收到胸前，站起身往右侧退开一步躲过壮汉的手，同时抬起左手拨开壮汉的手腕，长靴在裂开的泥土地上蹭起一阵黄沙；镜头跟着女孩后退的动作顺势摇到两人近景侧面，女孩转过四分之三侧脸盯着壮汉，胸口起伏喘气，荒漠的风吹动她额前的碎发，背后夕阳的金黄色光线照在两人的肩膀和侧脸上，画面里只有脚步声、呼吸声和风沙声。
```

### 范例 2：单人警觉起身（带首帧 + 1张白底角色三视图 + 1张白底道具图）
```text
傍晚破旧的废土加油站生锈铁柱旁，扎低马尾、穿深棕短款皮夹克和黑色短裤长靴的女孩（脸部和衣服与白底横版女孩三视图一致）半蹲在裂开的泥土地面上，双手捧着两端黄铜包裹、中间亮蓝光的玻璃圆筒管（与白底蓝光玻璃圆筒图一致）。镜头从侧面中景缓慢推近，女孩低头看着手里发蓝光的玻璃管，用大拇指擦掉玻璃管表面的灰尘，接着她像听到了右边的脚步声，把蓝光玻璃管收紧贴在胸口，扶着生锈铁柱慢慢站起身，转过四分之三侧脸看向画面右边，眼睛睁大盯着前方，嘴巴闭合，晚风吹动她的马尾碎发，夕阳金黄色的斜光从右侧照亮她的侧脸和皮衣边缘。
```

### 范例 3：纯环境空镜（仅带场景首帧图）
```text
傍晚金黄色夕阳下的荒漠废弃加油站，空旷的场地上没有人物，镜头贴近干裂的泥土地面缓慢往前推，阵阵大风卷起地面上的黄沙，吹过生锈倾斜的加油机和右侧停着的破旧油罐车，加油棚顶上垂下来的黑色断油管在风里轻轻晃动，夕阳把加油棚和油罐车的长影拉得很长，空气里飘着细小的沙尘颗粒，只有空旷的风声和生锈铁皮晃动的吱呀声。
```
