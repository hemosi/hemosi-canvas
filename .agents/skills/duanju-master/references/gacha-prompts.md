# 第四卷：跨模型短剧抽卡师与七层提示词母机（源自 `duanju-chouka` & `duanju-2-tishici`）

> **核心哲学**：抽卡贵，贵的不是单价，是次数。一段素材抽十次才能用，和抽两次就能用，差的是五倍的钱和时间。抽卡次数多，大多不是运气差，而是**提示词里让模型自己猜的地方太多**。
> 抽卡师只做两件事：
> 1. **写的时候，少让模型猜（靠锁定卡 + 素材分工 + 七层架构）。**
> 2. **废片出来以后，找到是哪一层没写清楚，只改那一层（靠 21 项废片诊断表）。**

---

## 第一章：第 0 步——跨模型参数路由与开工五问

写视频提示词前，一次问清用户未提供的信息（用户说「你看着办」则默认：真人写实、按分镜表切镜、时长按每10字2秒+1秒算、默认写法 A）：
1. **用哪个视频模型、在哪个平台跑**（见下表，用户说的和表不一样听用户的）；
2. **素材段落**（内容、时长、台词）；
3. **参考素材**（每张图/视频/音频分别是什么）；
4. **画风**（真人写实 / 3D 国漫 / 2D 动漫）；
5. **镜头切分**（一镜到底，还是要切镜头）。

| 视频模型 | 单段时长范围 | 参考素材上限 | 默认提示词写法 |
| :--- | :--- | :--- | :--- |
| **HemosiTV / Muse-Video（主力实测）** | `5–10 秒`（节点设置） | 角色卡 + 场景/首帧参考 | **写法 M：《Muse 10秒真人剧情视频提示词底板》（去大饼脸短剧叙事版，见 4.2 节）** |
| **MiniMax H3（RunningHub）** | `4–15 秒`（填整数） | 9 张图、3 段音频 | **写法 A / A-H3 分块写法**；多角色复杂调度可用 **写法 C 官方英文六段版** |
| **Seedance 2.5** | `4–30 秒` | 30 张图、10 段视频、10 段音频 | **写法 B Seedance 工业框架**；简单段落可用 **写法 B-短写法（120–320字）** |
| **可灵 3.0（Kling）** | `3–15 秒` | 按平台说明 | **写法 A 分块写法** |
| **其他模型 / 通用画布** | 按平台说明 | 按平台说明 | **写法 A 分块写法** |

> ⚠️ **容量铁律**：**模型能出多长，不等于一段该塞多少内容！** 一段只讲一件事：一个动作、一次情绪转折，或一两句关键台词。

## 第二章：第 1 步——先建一张「本剧锁定卡」（全剧唯一真理源）

一部剧只做一次，之后每一段都从卡里**原样复制**。人物和画风前后一致，一半靠这张卡（源自 `抽卡记录表.xlsx` 锁定卡标准）：

| 项目 | 角色 / 场景 / 称呼 | 对应参考图编号 | 固定写法（复制这一行，一字不改） | 备注 |
| :--- | :--- | :--- | :--- | :--- |
| **画风一句** | 全剧共用 | — | `真人写实电影质感，自然柔光，低饱和，浅景深，真实皮肤和毛发质感。` | 每段都原样复制 |
| **场景光** | 卧室（SC-001） | 卧室场景图 | `清晨暖光从画面右侧的窗户照进来。` | 一场戏锁死一句 |
| **角色** | 女主（CH-001） | 女主身份板 | `女主｜声音：二十出头的女声，刚睡醒，略带鼻音，语速慢，普通话。` | 称呼定了终身不改 |
| **角色** | 灰白小猫（CH-002） | 小猫身份板 | `灰白小猫｜声音：软软的小奶音，语速慢。` | 视觉标记当名字用 |
| **道具** | 青瓷茶杯（P-001） | 茶杯道具图 | `青瓷茶杯（直径约 8 厘米，一只手能握住，平时在女主左手）` | 必写尺寸+在谁手 |
| **全片要求** | 全剧共用 | — | `不要字幕和画面文字，不要背景音乐。` | 配乐留到剪映加 |

### 锁定卡三条铁律：
1. **称呼定了就不改**：第一段叫「灰白小猫」，以后每段都叫「灰白小猫」，绝不一会儿叫「小猫」、一会儿叫「猫咪」。
2. **视觉标记当名字用，绝不展开写长相**：长相 100% 交给身份板，文字只负责让模型知道说的是谁。
3. **卡里的句子，复制时一个字都不改**：想改先改锁定卡，再全剧统一换（这一段写「午后暖光」、下一段写「暖色午后阳光」，在模型眼里就是两种光！）。

## 第三章：第 2 步——给参考素材精准分工（九条黄金铁律）

**最高原则**：**一个素材只干一件事，并且在提示词里当场说清楚它干什么！**

| 参考素材类型 | 它只管什么（保留项） | 它绝对不管什么（剥离项） |
| :--- | :--- | :--- |
| **角色身份板 / 三视图** | 长相、发型、肤色、身材比例、服装 | 白底背景、分栏排版、多身体构图 |
| **场景图** | 空间布局、陈设风格、光的方向 | 人物 |
| **站位全景图** | 这场戏里谁站在哪、相对位置 | 具体特写机位 |
| **道具图** | 形状、材质、实际尺寸 | 在房间里的位置 |
| **首帧图** | 这一段从哪个画面开始 | — |
| **参考视频** | 运镜、动作或节奏（必写清只借哪一样） | 视频里原有的人和故事 |
| **参考音频** | 谁的说话音色，或什么参考音乐 | — |

### 参考素材分工 9 条死规矩：
1. **每个素材只点一次名，同一句写清用途**：如 `@图片1 是女主（只用长相和睡衣）`。后文提到她直接写「女主」，**不再重复写 `@图片1`**。严禁先把一串 `@` 列在开头、后面再解释，模型会分不清谁是谁。
2. **只放这一段出场的人**：没出场的角色，既不放图，也不在文字里提。
3. **一段只放一张场景图**：正打、反打、全景三张全塞进去，模型不知道用哪张，场景必乱！
4. **对话戏、三人以上的戏，放一张「站位全景」**（放进图片 3 起的框里）：比写一大段站位文字管用十倍。可提前用生图模型出，也可从上一段满意视频里截一帧全景。
5. **角色身份板/三视图必须说明「怎么读」**：常见三视图是上头像下全身（或左头像右全身），全身常不带头。**必须在提示词里告诉模型：`上半张管脸和发型，下半张管身材和衣服，白底、分栏和重复身体只作参考，不进画面`**！不写这句，画面极易变成白底或同一个角色分身成三个人！
6. **【核心防漂脸铁律】素材负责的，文字绝对不再写（图管静、字管动）**：
   - 给了人物身份板 ➔ **文字里严禁再写五官、脸型、发型、衣服颜色材质**！
   - 给了场景图 ➔ **文字里严禁再堆砌房间陈设**！
   - 文字只写这一段**会变的东西（表情、动作、位置）**。文字和图说得稍微有一点不一样，模型两头都想照顾，脸最容易漂！
   - 反过来，**只有身份板上没有画出来的细节，才在文字里每段写出来**（例如角色板上没画项圈，剧情需要项圈上的小铜牌）。
7. **只有真正传了视频参考，才写「保持上一镜一致」**：没传视频参考时，直接写这一段自己的画面关系。
8. **真人写实角色坚持用 AI 原创脸**：一直过不了平台审核，往往是角色图无意撞了某位明星/名人的脸，重新出一版角色图即可秒过。
9. **多角色同框段落，先单人试跑**：每个角色先单独跑一段 4–5 秒确认长相和声音稳了，再合到一起跑多人长段。

**输出前必给「素材编号表」**（编号严格对应上传顺序）：
```text
图片1 = 女主身份板（竖版三视图：上半管脸和发型，下半管身材和睡衣）
图片2 = 灰白小猫身份板
图片3 = 卧室场景正打（床靠墙，窗在画面右边）
```

## 第四章：第 3 步——七层提示词精解与四大标准写法

### 4.1 提示词内部七层检查清单（动笔前心里过一遍）

| 层级 | 核心回答什么 | 实操铁律与公式 |
| :--- | :--- | :--- |
| **1. 参考层** | 每个素材干什么 | 点名一次 + 写明三视图读取规则（白底分栏不入画） |
| **2. 风格层** | 画风一句 + 这一场的光 | 从锁定卡一字不差复制；**写具体参照，绝不写「电影感、高级感、氛围感」空话** |
| **3. 站位层** | 谁在左谁在右、机位在哪侧 | 多人戏**先写最显眼的人**；**一个人做大动作，其他人看**（所有人同时动必乱） |
| **4. 镜头层** | 几秒、切不切、景别机位运镜 | **一镜到底绝不写「切」**；**换镜头必写「切 + 景别」**（禁写“转到/来到/变成”）；**有台词镜头一律固定** |
| **5. 表演层** | 每一拍一个看得见的动作 | 拆成手、视线、身体、呼吸；有台词拆成「说之前（吸气）→ 说之时（移视线）→ 说之后（抿嘴）」 |
| **6. 声音层** | 谁开口、怎么说、什么音效 | 台词一字不改；严分「说 / 内心独白（嘴唇闭合不动） / 画外音」；**同一时刻只让一个人开口，写清先后**；让声音推动画面（如“门锁一响，她抬眼”） |
| **7. 保持层** | 必须守住什么、挡住什么 | 功能排除直接写（不要字幕/背景音乐/多出人）；**视觉毛病绝对禁止点名！** |

#### ⚡ 表演层外化双公式（彻底消灭抽象情绪词）：
- **表情公式** = `情绪 + 脸 + 眼神 + 嘴`
  > 例：`委屈，眼眶泛红，泪水在眼里打转，嘴角往下压`（绝不只写“她很委屈”）
- **动作公式** = `动作 + 情绪 + 身体状态 + 镜头`
  > 例：`她慢慢低下头，像是认输了，肩膀一点点塌下去，镜头缓慢推近`

#### 🛑 【H3 对照实测铁律】保持层：写你要的样子，绝不写你不要的视觉毛病！
- **功能性排除可以直接写**：`不要字幕和画面文字，不要背景音乐，画面里只有某某和某某，同一角色不要复制成多人`。
- **视觉上的毛病绝对禁止点名**：比如 `皮肤油光、脸上高光、手指变形、塑料感`，**哪怕前面加了「不要」也绝对别写！**
  > **实测案底**：在 H3 上用同一张图、同一个 seed 做对照实测，提示词里一旦点名「不要皮肤油光」，角色转头时脸上反而冒出一层白花花的油光；换成**只写正向想要的状态：`肤色稳定，毛孔自然，皮肤质感每一帧一致，柔和漫射光，曝光不变，手部动作自然`**，整段视频稳如泰山！

### 4.1b 写法 M：HemosiTV / Muse-Video 纯画面具体动作写法（主力默认）
- **核心铁律**：
  1. **严禁写文档标题和列表**：绝对禁止出现 `一、人物 / 二、站位 / 三、场景 / 四、镜头叙事 / 规则： / 负面排除：` 等小标题或项目符号！
  2. **靠描绘画面特征让模型认参考图（严禁写 `@图5 / @图30 / 角色A / 角色B`）**：传到视频模型后图片名称已经变了，模型看不到任何 `@图n` 编号或角色代号。必须直接描绘参考图里的外貌特征来指代人物和物品（如：`扎低马尾、穿深棕短款皮夹克和黑色短裤长靴的女孩（脸部与衣服和白底横版女孩三视图一致）`、`留络腮胡、穿红棕无袖皮马甲的壮汉（脸部与衣服和白底横版壮汉三视图一致）`、`两端黄铜包裹、中间亮蓝光的玻璃圆筒管（与白底蓝光圆筒道具图一致）`）。
  3. **严禁抽象词汇，只写具体肢体动作与镜头运动**：不写“压低重心戒备、神情冷冽、跨步逼近、交锋对峙”等抽象词，直接写谁站在哪边、迈步伸哪只手去抓什么、对方怎么收手后退躲开、镜头怎么推拉摇移。
- **标准范例**：
```text
夕阳下的破旧废土加油站前，画面左边站着留络腮胡、穿红棕无袖皮马甲和深色工装裤的壮汉（脸部和衣服与白底横版壮汉三视图一致），画面右边半蹲着扎低马尾、穿深棕短款皮夹克和黑色短裤长靴的女孩（脸部和衣服与白底横版女孩三视图一致），女孩右手握着两端黄铜包裹、中间亮着蓝光的玻璃圆筒管（与白底蓝光玻璃圆筒图一致）。镜头从正面中景缓慢往前推进，左边的络腮胡壮汉往前迈出一大步，弯腰伸出右手去抓女孩手里的蓝光玻璃管；右边的皮衣女孩迅速把蓝光玻璃管收到胸前，站起身往右侧退开一步躲过壮汉的手，同时抬起左手拨开壮汉的手腕，长靴在裂开的泥土地上蹭起一阵黄沙；镜头跟着女孩后退的动作顺势摇到两人近景侧面，女孩转过四分之三侧脸盯着壮汉，胸口起伏喘气，荒漠的风吹动她额前的碎发，背后夕阳的金黄色光线照在两人的肩膀和侧脸上，画面里只有脚步声、呼吸声和风沙声。
```

### 4.2 写法 A：通用分块写法（H3 / 可灵 3.0 / 通用模型主力）
每块各管一层，哪块出问题只改哪块：
```text
【素材段落 X】X 秒
【参考】@图片1 是……（只用……，白底分栏不入画）；@图片2 是……
【风格】（从锁定卡原样复制画风句 + 本场光线句）
【站位】（谁在左谁在右，摄影机在哪一侧，道具在谁手里及尺寸）
【画面】0–X 秒：景别，角度，固定 / 运动。画面里发生什么（按表情+动作公式写）。
X–X 秒：切近景，平视，固定镜头。……
【声音】某某说：「……」（语气 + 声音描述）；某某说完，另一人才说：「……」；某某内心独白：「……」（嘴唇闭合不动）；音效：……
【保持】画面里只有……；肤色稳定，皮肤质感每一帧一致；不要字幕和画面文字，不要背景音乐。
```

### 4.3 写法 A-H3：RunningHub H3 工作流专属分块写法（含上传框与禁用框指令）
专门配合 RunningHub 上的 9 图 3 音频 H3 工作流，直接把框位分配写进头部：
```text
【素材段落 X】（X 秒）
【上传】图片1：{主角身份板}　图片2：{单张场景图}　（图片3：{配角身份板/道具/站位全景}）　音频1：{声音参考，无则不开}；禁用框打开：图片1、图片2……
【参考】@图片1 = 某某的长相和服装（白底不入画），@图片2 = 某某场景……（有声音参考：@音频1 = 某某的声音）
【声音描述】某某：……（从锁定卡原样复制）
【站位】……
【画面】0–X 秒：景别，机位，固定/运动，画面动作与表情；光线：……
【声音】某某说：「……」（语气）；音效：……
【禁止】画面里只有……；道具不换手、不消失、不变大小，人物不瞬移，不改台词，肤色稳定，不要字幕和背景音乐。
```

### 4.4 写法 B：Seedance 2.5 完整工业框架（长段落 / 复杂多镜调度）
Seedance 2.5 支持 4–30 秒长段落与最多 30 图 10 视频 10 音频，多了「开场承接」与「结束帧交接」保证段落间无缝咬合，且每个分镜写到具体焦段（35mm/50mm/85mm）与焦点轨迹：
```text
【段落目的】这一段讲什么，在整集里起什么作用
【目标模型】Seedance 2.5【总时长】X 秒【画幅】9:16【目标分辨率】1080P

【全局风格与技术参数】
视觉引擎与美学：画风、风格参照（如仅转译某剧固定空间群戏的快速接话反应语法）、统一色谱、表演基调
画质与摄影：构图、帧率、焦段组（35mm/50mm/85mm）、景深、机位习惯
光影与环境：主光从哪来、补光、环境里的声光细节
音频与字幕：每个角色的声音描述（原样复制）、现场声、不生成任何可读字幕与额外配乐
连续性与物理逻辑：谁在哪、道具在谁手里、哪些边界不能越过（同一角色不复制成多人，肤色稳定）

【参考素材】人物 / 场景 / 道具 / 音色，每个点一次名并说明用途
【开场承接】这一段从什么画面开始，接上一段的哪里
【分镜头描述】
镜头1（0.00—3.30秒）：【景别／运镜】焦段、机位高度、焦点从哪跟到哪、具体动作、台词与先后顺序
镜头2（3.30—7.00秒）：切【景别／运镜】……
【结束帧交接】这一段最后停在什么画面，下一段怎么接（如：下一段以同一只茶杯作匹配切）
```
- **写法 B-短写法（Seedance 2.5 简单单人/一两镜快速测试，严控 120–320 字）**：
  ```text
  【风格】一句话具体风格参照与光线。
  【参考】@图片1 锁定……；@图片2 锁定……
  X 秒，X 个镜头。0–X 秒：景别，机位，固定镜头，站位、动作、台词与先后顺序、音效。X–X 秒：切景别，……
  【排除】不生成任何可读文字，不生成背景音乐。
  ```

### 4.6 两个高性价比特殊提示词模板
1. **主要角色「无台词反应镜头」模板（每角色顺手多写 2–3 段，每段 3–5 秒）**：
   - 不说话、嘴巴闭合，只做表情（瞪大眼睛震惊、嘴角冷笑、众人面面相觑）。剪辑时盖在长台词中段，便宜又好剪！

## 第五章：第 4 步自检与第 5 步「废片诊断急救系统」

### 5.1 出提示词前 10 项强制自检
- [ ] 1. 素材编号表和上传顺序严格对得上；没出场的角色绝没放图。
- [ ] 2. 每个素材只点了一次名，同一句写清用途；文字没有重复描述图里已有的长相、衣服、陈设。
- [ ] 3. 画风、场景光、角色称呼、声音描述，和本剧锁定卡一字不差。
- [ ] 4. 站位写清了左右、摄影机在哪一侧、道具在谁手里及尺寸。
- [ ] 5. 一镜到底没写「切」；换镜头都写了「切 + 景别」；没传视频参考时没写「延续上一镜」。
- [ ] 6. 每一拍只有一个动作；没有「很难过」这种拍不出来的词；有台词的镜头摄影机固定。
- [ ] 7. 台词一字不差；说 / 内心独白（嘴唇闭合不动） / 画外音分清；同一时刻只一人开口，先后写清。
- [ ] 8. 时长在目标模型上限以内，台词放得下（5 秒最多一两句）。
- [ ] 9. 保持/排除层**没有点名任何视觉毛病**；有真人脸的段落写了「肤色稳定，皮肤质感每一帧一致」。
- [ ] 10. 用写法 B 时每镜标了秒数且首尾交接对齐；用写法 B 短写法时字数在 120–320 字之间。

### 5.2 抽卡与修改法则：先判运气还是提示词，再「一次只改一层」
1. **二步判定法（运气 vs 提示词）**：
   - 同一版提示词先看 2–3 次结果：
   - **每次废的地方都不一样** ➔ **运气问题**，改个 seed（换一抽）再试；
   - **两次以上废在同一个地方** ➔ **提示词问题**，原样再抽十次也是废片！立刻查下方《21 类废片诊断速查全表》。
2. **重抽前的省钱救片三原则**：
   - **① 能剪就剪**：问题只在开头或结尾几帧，直接留到剪映里剪掉，记入出片表，不重抽！
   - **② 能补就补**：问题在中间一小段，截下出问题前那一帧当首帧（有穿帮先用生图模型修好那一帧），只补生成那 2–3 秒！
   - **③ 最后才重抽**。
3. **【黄金铁律】一次只改一层（控制变量法）**：
   - 改提示词时，**参考素材、上传顺序、seed、时长、分辨率全部锁死不动，只改诊断表指向的那一层！**
   - 改完和上一版对比同一秒的原尺寸大图。一次乱改三处，好了不知道哪处立功，坏了不知道退哪处。
   - 输出改版提示词时，代码块上方用一行写明：`v0X 版本｜改了【XX层】：具体改了什么`，代码块内给完整可直接复制的新提示词。

### 5.3 《21 类废片症状精准诊断与改法速查全表》（源自 `duanju-chouka` & `抽卡记录表.xlsx`）

| 序号 | 废片具体症状 | 先改哪一层 | 精准根治改法 |
| :--- | :--- | :--- | :--- |
| **1** | **脸变了，不像同一个人** | `参考 ➔ 镜头` | ①身份板干净、一人一张；②**删掉文字里的五官长相描述**；③**把转头、转身的幅度改小（如“头只微微转向右侧，主要靠眼神看过去”），或拆成两个固定镜头**；④景别拉近一档；⑤光的方向和冷暖全段不变；⑥时长缩短。 |
| **2** | **一个角色分身变成两个，或多出无关路人** | `参考 / 保持` | ①只放本段出场角色的图；②三视图写明「上半管脸、下半管身材，白底分栏和重复身体不入画」；③保持层写`画面里只有某某和某某`、`同一角色不要复制成多人`。 |
| **3** | **人物左右颠倒、突然瞬移** | `站位` | ①写清谁在左谁在右、摄影机在哪一侧（严守 180° 轴线）；②图片 3 加喂一张「站位全景图」；③开头动作接上一段的结尾状态。 |
| **4** | **场景一会儿一个样、背景乱跳** | `参考` | **一段视频只放一张场景图**（正打/反打/全景三选一，绝不同时塞三张）；确认场景图里没有人。 |
| **5** | **镜头乱晃乱动、景别不对** | `镜头` | 先锁摄影机：写死`固定镜头`，或写清机位在哪、离多远、怎么平稳运动、最后停在什么画面。 |
| **6** | **想切镜头没切，或不该切的乱切了** | `镜头` | ①要切的地方必须明确写`切 + 景别`（如`3.3–7 秒：切近景，平视，固定镜头`），禁写“转到/变成”；②一镜到底的段落删掉所有「切」字。 |
| **7** | **动作做错、多出奇怪动作** | `表演` | ①一拍只写一个动作；②大动作拆成「准备 → 执行 → 结果」三步；③写清用左手还是右手。 |
| **8** | **人物木讷僵硬，像假人木偶** | `表演` | 把表演拆成手、呼吸、身体、视线微动作：`说话前先轻轻吸一口气，说到一半移开视线，说完抿住嘴`。 |
| **9** | **多人的戏乱成一团** | `站位 / 表演` | ①站位先写画面里最显眼的那个人；②**同一时间只让一个人做大动作，其他人保持静止看着他**。 |
| **10** | **画面太死板、像静止插画** | `镜头 / 表演` | 加一点环境微动态：微风吹动发丝/衣角、袅袅茶烟、摇曳烛火、窗外掠过的车影。 |
| **11** | **嘴型对错了人、台词串到别人嘴上** | `声音` | ①**同一时刻只让一个人开口，写清先后顺序**（如`小猫说完，女主才闭着眼说……`）；②没说话的人明确写`嘴巴闭合看着对方`。 |
| **12** | **心里话张着大嘴念出来** | `声音` | 把「说」改成`某某内心独白：「……」（嘴唇闭合不动，不念出声）`。 |
| **13** | **角色声音换了人、前后段音色不一致** | `声音` | ①每段【声音描述】从锁定卡一字不差原样复制；②从第一段满意视频里剪出 3–5 秒干净人声传进 `@音频1` 当声音参考。 |
| **14** | **口型对不上台词** | `声音 / 镜头` | ①台词减量（5 秒最多放一两句短台词，太长就拆段）；②台词前写清语气；③**说话时镜头必须固定不推拉**。 |
| **15** | **皮肤发油、白花花反光、塑料蜡像感** | `保持 / 风格` | ①**删掉提示词里所有描述这些毛病的词（包括“不要油光、不要塑料感”）**；②改写正向词：`肤色稳定，毛孔自然，皮肤质感每一帧一致，柔和漫射光，曝光不变`。 |
| **16** | **画面底部冒出假字幕、墙上出乱码字** | `保持` | 写明`不要字幕和画面文字`（Seedance 写`不生成任何可读文字`）。 |
| **17** | **自己乱配了诡异背景音乐** | `保持` | 写明`不要背景音乐`；写法 C 的 `non_diegetic_music` 填 `None.`。 |
| **18** | **画风、色调和上一段对不上** | `风格` | 画风句和本场场景光句，必须从「本剧锁定卡」一字不差原样复制。 |
| **19** | **道具忽大忽小、自动换手、凭空消失** | `站位` | ①写清道具实际尺寸（如`直径约 8 厘米，一只手能握住`）；②写死在谁手里、哪只手；③上传道具设定图。 |
| **20** | **动作没做完视频就戛然而止了** | `镜头` | 这一段塞的内容太多，拆成两段视频，或者删减台词字数。 |
| **21** | **画面平庸，没有电影感** | `风格 ➔ 镜头 ➔ 表演 ➔ 环境` | 按顺序升级：①风格换成具体电影参照（ARRI+Cooke+侧光/伦勃朗光）；②机位高度、焦段（50mm/85mm）、焦点落点写清；③表演拆细微动作；④加环境微动态。绝不靠堆砌“电影感”三个字。 |
