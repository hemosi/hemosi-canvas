# 第二卷：电影级光影与摄影机视听词典（源自《光影与摄影机速查.pdf》全25页）

> **核心认知**：为什么新手做出来的 AI 短剧画面一眼「假」？十有八九不是脸不像——而是**光是平的、色温乱的，镜头全是平视固定的大头照**。画面「平、板、像拼的」，一眼就露 AI 味。
> **光影负责「真实感与情绪」，摄影机负责「叙事与节奏」**。这两块就是「生成图」与「拍出来的电影戏」的分水岭！

## 第一章：光影制作系统（LIGHTING · 决定画面「像不像真的」）

### 1.1 新手在光影上最常犯的 3 个错
1. **错误 1：只会「平光」** —— 不写光源方向，AI 默认给正面平光，画面平、无立体、无氛围，像证件照。
2. **错误 2：色温 / 影调乱** —— 这镜暖那镜冷、忽明忽暗，全片没锁一套光，多镜头一接就「像拼的」。
3. **错误 3：塑料 / 过曝** —— 光太满太平、皮肤过曝无层次，缺暗部层次和眼神光，满脸塑料感、蜡像感。

### 1.2 光的语言：4 个基本维度（写提示词必含）
任何一束光都从这 4 个维度描述，写清楚了 AI 才不会随机给平光：
- **① 方向（光从哪来）**：顺光 / 侧光 / 逆光 / 顶光 / 底光
- **② 光质（软还是硬）**：硬光（锐利阴影） / 软光（柔和过渡）
- **③ 色温（暖还是冷）**：暖调（黄橙，约 3000K 以下） / 冷调（蓝，约 6000K 以上）
- **④ 影调与光比（亮还是暗）**：高调（整体偏亮、阴影少） / 低调（整体偏暗、大面积阴影） + 光比大小（大光比=明暗反差大、戏剧硬朗；小光比=反差小、柔和日常）

### 1.3 光源方向：同一张脸，6 种完全不同的味

| 光位 | 画面效果 | 适合的戏 / 情绪 | 提示词方向（中/英） |
| :--- | :--- | :--- | :--- |
| **顺光（正面光）** | 平、干净、少阴影、缺立体 | 干净日常，但极易平淡显假 | 正面平光 / `front light, flat` |
| **侧光（45°/90°）** | **强立体、有质感、有层次** | **人物塑造、情绪、质感（主力首选）** | 侧光 / `side light` |
| **伦勃朗光** | **暗侧颧骨三角光，电影感极强** | **人物特写、严肃、悬疑、情绪顶点** | 伦勃朗光 / `Rembrandt lighting` |
| **逆光 / 轮廓光** | 勾轮廓、通透、剪影氛围 | 意境、回忆、唯美、出场勾边 | 逆光、轮廓光 / `backlight, rim light` |
| **顶光** | 眼窝鼻下重影，压抑神秘 | 反派、审讯、诡异、威压 | 顶光 / `top light` |
| **底光（脚光）** | 反常、恐怖、威胁感 | 惊悚、恐怖、变脸、阴谋 | 底光、脚光 / `under light, uplight` |

> 💡 **讲师提醒**：默认最常翻车就是「顺光/平光」。**想要电影感，先从「改成侧光或伦勃朗光」开始！**

### 1.4 光质对比：硬光 vs 软光

| 维度 | 硬光（Hard Light） | 软光（Soft Light） |
| :--- | :--- | :--- |
| **光源特征** | 光源小 / 远（如正午太阳、裸灯、聚光灯） | 光源大 / 近 / 被柔化（柔光箱、阴天、窗纱透光） |
| **阴影与对比** | 阴影边缘锐利、明暗对比强（大光比） | 阴影柔和过渡、明暗对比低（小光比） |
| **画面气质** | 硬朗、紧张、戏剧、有力量 | 柔和、高级、干净、皮肤质感好 |
| **适用戏份** | 悬疑、冲突、对决、阳光直射、正午外景 | 人像特写、女主戏、抒情、日常温情 |
| **提示词写法** | 硬光，锐利阴影，高反差 / `hard light, harsh shadow, high contrast` | 柔和漫射光，低反差 / `soft diffused light, low contrast` |

### 1.5 色温与影调组合矩阵
- **暖调（黄橙 <3000K）**：温暖、亲密、怀旧、治愈；
- **冷调（蓝 >6000K）**：冷峻、紧张、孤独、夜感；
- **高调（偏亮少影）**：干净、明快、日常、喜剧；
- **低调（偏暗多影）**：压抑、情绪、悬疑、夜戏；
- **组合公式**：`暖低调 = 烛光/古装夜戏`；`冷低调 = 悬疑/危机夜戏`；`暖高调 = 午后庭院/治愈日常`。

### 1.6 角色定妆图标准打法：影棚三点布光（Three-Point Lighting）
做「角色设定图 / 三视图 / 身份板」时最该用的一套光——干净、统一、能看清人：
- **主光（Key Light · 正左侧）**：主要光源，决定明暗方向和立体感；
- **辅光（Fill Light · 正右侧）**：补亮暗部、控制光比，别让阴影太死；
- **轮廓光（Rim Light · 后右侧）**：勾出边缘、把人从背景里分离出来。
- **定妆图标准光影句**：
  > `干净统一的摄影棚三点式打光，正左主光、正右辅光、后右轮廓光，纯净白色/灰色无缝背景`（严禁写彩色灯光、严禁写杂乱光效——定妆图越干净，后面视频一致性越稳！）

### 1.7 4 种经典人像光型（拍脸特写时的区别）
1. **伦勃朗光（Rembrandt lighting）**：暗侧颧骨下一块倒三角光斑 ➔ **电影感、情绪、深度**（特写与情绪戏点名首选）。
2. **蝴蝶光（Butterfly lighting）**：正上方偏前，鼻下有蝴蝶状影 ➔ **优雅、美妆、女性魅力**。
3. **环形光（Loop lighting）**：略偏一侧，鼻侧短影成环 ➔ **自然、通用、最百搭**（日常戏最稳）。
4. **分割光（Split lighting）**：90° 正侧，脸一半亮一半暗 ➔ **强烈、戏剧、内心正邪冲突**。

### 1.8 场景光影速查表：什么戏用什么光

| 光影类型 | 画面感觉 | 适合的戏 | 提示词写法（中/英） |
| :--- | :--- | :--- | :--- |
| **黄金时段暖光** | 温暖、氛围、治愈 | 日常、情感戏、重逢 | 黄金时段柔和暖光 / `golden hour, warm soft light` |
| **柔光人像** | 干净、高级、皮肤好 | 特写、女主戏、室内 | 柔和漫射光 / `soft diffused light` |
| **低调夜戏** | 冷峻、紧张、神秘 | 夜戏、悬疑、潜入 | 低调暗光，冷色调夜戏 / `low-key, cool tone, night` |
| **逆光轮廓** | 通透、剪影、氛围 | 意境、回忆、登场 | 逆光轮廓光 / `backlight, rim light` |
| **烛光 / 火光** | 暖橙、摇曳、亲密 | 古装夜戏、情感、密谋 | 摇曳暖橙烛光 / `candlelight, warm flickering` |
| **雷光 / 冷闪** | 冷蓝、短促、惊悚 | 惊变、冲突瞬间、反转 | 冷蓝雷光闪烁 / `cold blue lightning flash` |

> 💡 **主光基调铁律**：一部片或一场戏先定一个「主光基调」（如全场黄金时段暖光），**只有情绪爆点才换光（如雷光冷闪）——绝不要每镜换光！**

### 1.9 光影一致性与「去塑料/蜡像感」四大实操技法
- **保持多镜头一致性的 4 条规矩**：
  1. 全场锁定一套光：同一光源方向 + 同一色温；
  2. 人和景的光要对上：人身上暖光，背景绝不能冷光；
  3. 同场景多镜头，光位保持一致，别忽左忽右；
  4. 后期剪映统一调色兜底，把各镜色调拉齐。
- **用光去掉「塑料 / 蜡像感」的 4 味解药**：
  1. **加眼神光（`catchlight in eyes`）**：让死板的眼睛瞬间“活”过来；
  2. **保留暗部层次（`soft shadows with detail`）**：别把阴影打死、别全片过曝；
  3. **避免平光满打**：留一侧暗面，才有立体感和真实皮肤纹理；
  4. **加胶片颗粒（`film grain`）**：去掉 AI 生图“太干净、太数码”的假味。

### 1.10 两种典型戏打光实操对比（《羊羊剧》案例）
- **案例 A：日戏 · 书院庭院（1-1 喧闹光明正大的对决）**
  - 拆解：方向=明亮午后硬光（顶侧向）；光质=硬光，青石板上有锐利光斑；色温/影调=偏暖、高调、通透。
  - **直接抄写句**：`明亮的午后阳光斜射，硬光，青石板反光，暖色调，画面通透，高调，真实皮肤纹理。`
- **案例 B：夜戏 · 红帐婚床（暧昧、危机、戏剧张力）**
  - 拆解：方向=红烛边光勾轮廓（侧逆）；光质=低照度、暗部保留层次；色温/影调=暖红为主 + 冷蓝雷光穿插。
  - **直接抄写句**：`低照度暖红烛光，冷蓝雷光短暂扫过脸部，红烛边光勾出轮廓，暗部有层次，肤色稳定，柔和阴影细节。`

## 第二章：摄影机制作系统（CAMERA · 决定镜头「会不会讲故事」）

### 2.1 新手在摄影机上最常犯的 3 个错
1. **错误 1：景别单调** —— 全片中景大头，没有远近变化，画面平、没重点、没节奏。
2. **错误 2：机位平铺** —— 永远平视固定，像监控摄像头，人物没气势、没情绪张力。
3. **错误 3：运镜乱推拉** —— 台词时还在推拉摇晃、一个镜头塞好几种运镜，画面乱、口型必崩。

### 2.2 摄影机三要素框架
**一个镜头 = 景别（离多近·控看多少） + 机位角度（什么高度·控心理） + 运镜（动不动·控节奏）**。

### 2.3 6 种景别的区别与用法

| 景别 | 画面范围 | 作用 / 情绪 | 建议时长 |
| :--- | :--- | :--- | :--- |
| **远景** | 大环境、人很小 | 交代时空、气势、开场、转场 | 3–4 秒 |
| **全景** | 人物全身 + 空间关系 | 交代人物位置关系、走位、大动作 | 3–4 秒 |
| **中景** | 膝盖 / 腰以上 | 对话主力、双人互动、推进剧情 | 2–3 秒 |
| **近景** | 胸部以上 | 情绪、表情变化、说话与反应主力 | 2–3 秒 |
| **特写** | 面部 / 关键道具 | 强情绪爆发、关键细节、高潮顶点 | 2–3 秒 |
| **大特写** | 眼睛 / 嘴唇 / 手指局部 | 极致情绪、瞳孔地震、结尾钩子 | 2–3 秒 |

> ⚡ **节奏铁律**：**严禁连续三个镜头使用相同景别！** 用「远—全—中—近—特」交替，画面才有呼吸和重点。

### 2.4 5 种机位角度：用高度操控观众心理
- **平视（Eye-level）**：相机与视线齐平 ➔ **客观、自然、平等**（最常用基础机位）。
- **俯拍（High angle）**：相机在上往下拍 ➔ **显弱小、被压制、无助、或交代全局**。
- **仰拍（Low angle）**：相机在下往上拍 ➔ **显强大、威严、压迫感**（拍反派嚣张或主角起势必用）。
- **过肩（Over-the-shoulder, OTS）**：越过一方肩膀（前景虚化）拍对面的人 ➔ **对话戏标配，交代双方空间位置关系**。
- **主观视角（POV）**：代表角色的眼睛看出去 ➔ **强代入感、紧张、第一视角惊悚或审视**。

### 2.5 9 种运镜的区别与三条死纪律

| 运镜 | 镜头怎么动 | 效果 / 用在哪 |
| :--- | :--- | :--- |
| **固定（Locked-off）** | 机位完全不动 | **稳定客观，聚焦表演 —— 所有台词戏首选！** |
| **推（Push in）** | 镜头缓慢靠近主体 | 聚焦情绪、强调细节、起势递进 |
| **拉（Pull back）** | 镜头缓慢远离主体 | 交代环境、揭示孤立处境、场面收尾 |
| **摇（Pan/Tilt）** | 机位不动，镜头左右/上下转 | 扫视环境、跟随人物视线转移 |
| **移 / 跟（Track/Follow）** | 机位平移 / 跟着人走 | 陪伴感、行动动线、追随步伐 |
| **环绕（Orbit）** | 绕着主体旋转 | 展示人物气场 / 核心道具、仪式感 |
| **升降（Crane）** | 机位垂直上升或下降 | 烘托宏大气势、情绪大起大落 |
| **手持（Handheld）** | 带有轻微呼吸晃动 | 纪实感、紧张混乱、临场压迫感 |

> 🛑 **运镜三条铁纪律**：
> 1. **一个镜头只用一种运镜**（严禁又推又摇又环绕）；
> 2. **运动必写「缓慢 / 平稳」**（防画面撕裂变形）；
> 3. **台词时段固定镜头、绝不推拉（推拉必崩口型与台词）！**

### 2.6 4 档焦段镜头语言（讲师口诀：越广越交代环境，越长越突出人越虚背景）

| 焦段 | 适用场景 | 画面气质 | 实战选焦口诀 |
| :--- | :--- | :--- | :--- |
| **24–28mm（广角）** | 空间关系、双人中景、移动方向 | 视野广、有空间纵深、交代环境 | 开场交代大场面用 `24–35mm` |
| **35mm（小广角/人文）** | 常规中近景、人物关系、对手戏 | 自然、耐看、透视舒适、最百搭 | 常规叙事与多人互动主力 |
| **50mm（标准镜）** | 人物近景、正反打、情绪反应 | 接近人眼视觉、真实无畸变 | 对话戏的正反打与情绪反应首选 |
| **85mm（人像长焦）** | 眼神特写、强情绪落点、结尾钩子 | 强烈背景虚化（浅景深）、突出人物 | **高潮面部特写、结尾钩子眼神必用 `85mm`！** |

> 🌸 **林佳佳实战心法补注（防大饼脸焦段秘诀）**：
> 老公，之前咱们遇到人物特写变「大饼脸」，很大一部分原因就是生图或视频模型在近距离默认用了广角透视！在写近景和特写提示词时，明确加上 **`50mm` 或 `85mm` 镜头，浅景深，背景虚化**，模型会自动切到长焦人像的平坦透视，脸型立刻修长立体，再也不会鼓成大饼脸！

### 2.7 真人实拍「电影质感」默认黄金配方
当画风为「真人写实 / 古装真人电影」且未指定特殊风格时，将以下配方作为固定后缀嵌入风格层，画面立刻拥有顶级电影底子：
> **`ARRI Alexa 35 电影机质感，Cooke S4/i 镜头，35mm/50mm，Kodak Vision3 胶片颗粒，低对比，低饱和，真实皮肤纹理，暗部保留层次，眼神光清晰。`**
*(注：2D / 3D 国漫风格时，保留焦段、景别、光影、色调的描述，但**不要写 ARRI/Cooke/Kodak 等真实摄影机与胶片品牌**。)*

### 2.8 4 套黄金镜头组合套路（拆镜时直接套用，`→` 即切镜点）
1. **【对话戏套路】**：`正打近景 → 反打近景 → 手部/道具特写 → 双人关系中全景`
2. **【危机戏套路】**：`人物反应近景 → 关键道具特写 → 双人关系中景 → 情绪落点特写`
3. **【追赶/动作戏套路】**：`动作起点 → 双人空间关系 → 接触动作瞬间 → 反应落点`
4. **【结尾钩子套路】**：`反差台词（近景固定） → 对方沉默僵住（中近景） → 眼神/手部大特写死死停住`

### 2.9 镜头设计实操案例：高潮戏 5 镜递进（《羊羊剧》平静 ➔ 震撼）

| 镜号 | 景别 | 机位 | 运镜 | 导演设计意图 |
| :--- | :--- | :--- | :--- | :--- |
| **10** | 全景 | 平视 | 拉 | 镜头拉开、众人安静，从喧闹转肃杀，把羊羊放在视觉中心 |
| **11** | 近景 | 平视 | 推 | 推近 + 迈步，气场突变，眼神变锐，起势蓄力 |
| **12** | 特写 | 平视 | 固定 | 面部特写、背景虚化，眼中光影闪烁，暖转白亮 —— **情绪顶点** |
| **14** | 全景 | 平视 | 固定 | 对称构图、全场僵住，用极致的「静」反衬前面的「爆」 |
| **15** | 特写 | 斜角（荷兰角） | 固定 | 切反派李秀才瞳孔地震，斜角构图传达心理失衡崩塌 —— **反应落点** |

## 第三章：光影 × 摄影机 = 单镜头六要素合一公式与翻车速查

### 3.1 单镜头六要素完整公式（少写一样，AI 就自己乱猜）
```text
（1.运镜），（2.景别），（3.机位角度），（4.主体：谁、什么神情），（5.运动：动多少）；（6.光影：方向、软硬、冷暖、明暗）；（焦段），电影质感，真实皮肤纹理，暗部有层次，面部清晰不变形。
```
- **实战成品示范（羊羊第 12 镜情绪顶点）**：

### 3.2 光影 & 摄影机翻车速查表

| 翻车症状 | 一句话根治解法 |
| :--- | :--- |
| **画面平、没立体感** | 别用顺光/平光，改成**侧光**或**伦勃朗光**，明确给出光源方向 |
| **多镜头像「拼出来的」** | 全场锁死一套光（同方向 + 同色温），后期剪映统一调色 |
| **塑料脸 / 蜡像感 / 过曝** | 加**眼神光**、留**暗部层次**、加**胶片颗粒**，绝不满打平光 |
| **景别单调、没重点** | 「远—全—中—近—特」交替，绝不连续三个相同景别 |
| **人物没气势 / 没张力** | 按情绪选机位：**显强用仰拍、显弱用俯拍**、失衡用斜角 |
| **画面乱晃、台词口型崩** | 一镜只用一种运镜；**凡有台词时镜头一律固定不推拉** |
| **只会空写「电影感」** | 把光写具体（方向+光质+色温），套用「ARRI + Cooke + 胶片颗粒」配方 |
