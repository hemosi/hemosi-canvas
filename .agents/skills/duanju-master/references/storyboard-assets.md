# 第三卷：专业分镜拆解与美术资产工程（源自 `duanju-storyboard` & `duanju-2-tishici`）

> **核心界限**：剧本写的是「发生了什么」，分镜写的是「**观众每一秒看到什么**」。
> *(注：10 秒新手路线可跳过分镜表，直接出 1 张角色图 + 1 张场景图 + 1 段视频提示词；完整一集或对白多、想精准控节奏时，必须先拆站位与分镜表。)*

## 第一章：五步专业分镜拆解工作流（`duanju-storyboard` 完整规范）

按顺序走：**第 0 步问清楚 ➔ 第 1 步定站位 ➔ 第 2 步按规则拆镜头 ➔ 第 3 步出七列分镜表 ➔ 第 4 步自检 ➔ 第 5 步合成素材段落**。

### 1.1 第 0 步：开工前问清楚
一次问完，用户已给的不再问（成片画幅直接读取界面设置，无需再问）：
1. **剧本**：贴一场戏或一整集。若剧本是小说段落、格式不规范，先把每一句标成「画面 / 台词 / 内心独白 / 画外音 / 音效」，给用户确认后再拆。
2. **画风与核心造型**：真人写实 / 3D 国漫 / 2D 动漫，以及主角核心造型。
3. **目标时长与视频模型**：默认一集 5 分钟以内，按台词量算时长。

### 1.2 第 1 步：先定「站位表」（防瞬移、防左右颠倒的定海神针）
每场戏拆镜前，**必须先写一张站位表**。后面每个镜头和每段视频提示词都照抄它：

| 项目 | 写什么 |
| :--- | :--- |
| **场景与光线** | 场号、地点、内/外、日/夜，加一句**全场固定的光线句**（如「午后暖色硬光，从画面右侧照进来」） |
| **方位** | 谁在画面左、谁在右；门、窗、桌子这些固定陈设在哪一边 |
| **机位侧（180°轴线）** | **摄影机在哪一侧。对话戏的所有镜头都在两人连线的同一侧拍，绝不越过这条线，左右才不会反！** |
| **道具** | 关键道具在谁手里、哪只手、朝哪个方向 |
| **移动方向** | 有人走动或奔跑时，固定从画面哪边到哪边 |

*(剧本没写的方位，按剧情给一个合理安排，标上「（建议）」，请用户确认。)*

### 1.3 第 2 步：七大黄金切镜规则与时长公式
- **七大切镜规则**：
  1. **换人说话就切**：`说话的人 → 听的人的反应 → 说话的人`。**台词超过 20 字左右，中途必须切一次听的人的反应**，台词声音不断，这几秒标成`画外音`。
  2. **情绪变一次，切一次**：平静到震惊、震惊到愤怒，每次变化给一个独立镜头。
  3. **大动作拆三步**：`准备 → 执行 → 结果`。复杂动作拆 3–5 个镜头。**一个镜头只做一件事**。
  4. **换场景、跳时间必须切**：两场之间留 1–2 秒转场镜头（如空镜、门关上、天色变化）。
  5. **内心独白单独成镜**：**人物闭着嘴**，画面给眼神与微表情，声音是心里话。
  6. **景别要有变化**：不连续 3 个镜头用同一种景别。
  7. **每个镜头都要有用**：推进事件、交代信息或给情绪，三者必占一样，不用废空镜凑时长。
- **单镜时长核算标准**：
  - 远景、全景：`3–4 秒`；中景：`2–3 秒`；近景、特写：`2–3 秒`
  - 有台词：按 **每 10 个字约 2 秒** 计算，再留 `0.5–1 秒` 呼吸余量
  - 听者反应镜头：`1 秒左右`；高潮镜头：`3–5 秒`
  - **硬上限**：单个镜头不超过 `10 秒`

### 1.4 第 3 步：输出标准七列分镜表
一场戏一张表，表后写本场总时长：

| 镜号 | 时长 | 景别 | 机位和运动 | 画面内容 | 台词和音效 | 入镜角色 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |

- **镜号铁律**：场号加两位序号，如 `1-1-01`。**定了就终身不改**：中间插镜用 `1-1-03a`，删掉的镜号空着，绝不整体重排（防后续提示词与素材文件名全乱）。
- **景别**：远景 / 全景 / 中景 / 近景 / 特写 / 大特写。
- **机位和运动**：角度（平视/俯拍/仰拍/过肩/斜角）+ 运动（固定/推/拉/摇/跟）。有台词默认写`固定`。
- **画面内容**：一段话写全「画风、环境、谁在哪（按站位表）、动作、表情、光线、构图」。只写镜头拍得到的，补上的细节标「（建议）」。
- **台词和音效**：台词与剧本一字不差，标明「`某某说` / `某某内心独白` / `某某画外音`」（括号写语气）+ `音效：……`。无则写 `—`。

### 1.5 第 4 步：分镜表 7 项自检
- [ ] 每镜时长加起来，和目标时长对得上
- [ ] 每个镜头只做一件事
- [ ] 换人说话都切了；长台词中途有反应镜头
- [ ] 没有连续 3 个镜头同景别
- [ ] 台词和剧本一字不差，三种类型标对；内心独白的镜头写了「嘴唇闭合不动」
- [ ] 人物左右、门的方向、道具在谁手里，都和站位表一致
- [ ] 开头 3 秒有冲突，结尾停在悬念上

### 1.6 第 5 步：合成 5–15 秒视频素材段落
AI 视频模型一次生成的是一段素材（5–15 秒），不是单帧单镜。将连续的 **2–4 个镜头**合成一段素材：
- 同一场景、同一时间的镜头才合在一起；
- 一段里最多放一两句关键台词（5 秒段落最多一两句）；
- 情绪转折、高潮镜头可单独成段。
- **标准输出格式**：
  ```text
  素材段落 1：1-1-01 ～ 1-1-02（6.3 秒）｜被猫舔醒
  素材段落 2：1-1-03 ～ 1-1-04（6.4 秒）｜对视，猫开口
  ```

## 第二章：三类美术资产清单与出图提示词工程（源自 `duanju-2-tishici`）

### 2.1 资产汇总与编号规则（全程用固定编号指代）
1. **人物（`CH01`、`CH02`……）**：只列有台词或有特写的角色，群众演员不单独设计。同一角色换装写成 `CH01-A`、`CH01-B`。
2. **场景（`S01`、`S02`……）**：每个地点一项。**凡有对话的场景必须出三张图**：
   - `S01-正打`（从 A 这边看过去）
   - `S01-反打`（从 B 这边看过去）
   - `S01-站位大全景`（能一眼看清所有人站位关系的全景图）
3. **道具（`P01`、`P02`……）**：被拿起、被特写、或者剧情要用到的关键物件。
4. **必附对照表**：输出一张 `资产编号 → 用在哪几个素材段落` 的映射表，方便下一步分配工作流图片框。

### 2.2 出图提示词通用铁律
1. **生图提示词双轨规则（按有无参考图区分）**：
   - **没参考图（`refs` 为空 · 波次 1）**：只写画面里看得见的正向视觉内容；不写“生成一张”等元指令，不用“不要/没有/不戴/不拿/无人”等否定词（用“纯白无缝影棚背景”代替“没有背景”，用“空旷寂静的纯环境空镜”代替“没有人”）。
   - **有参考图（`refs` 非空 · 波次 2 如反打、换装、衍生图）**：**第一句直接说改什么**（例：`镜头转到对面，看向油罐车背后的荒地，光源转为左后方顺光`），后面只写新出现的内容，**不重复参考图里已有的物体、不堆画质词**。
2. **DAG 分波次出图铁律（严禁同批并发弹出依赖资产）**：
   - **波次 1（独立基础资产）**：先只弹出角色正面全身设定图、主场景正打（`S01`，拆景时先定正打朝哪边，不要把拍全两侧的大全景当单向正打）、独立道具（`P01`，比例 `1:1`）；
   - **波次 2（依赖衍生资产）**：必须等波次 1 出图后，下一轮再把波次 1 的 `@图n` 填入 `refs` 弹出 `S02-反打`（只拍正打对面的空间）、角色身份板（参考角色正面全身图 `@图n`）或换装图 `CH01-B`。
3. **无参考图的基础资产开头加同一句「画风句」**，全剧保持一致：
   - **3D 国漫**：`3D 国漫风格，UE5 渲染质感，干净高清，细节丰富。`
   - **2D 动漫**：`2D 日系动漫风格，赛璐璐上色，线条干净，色彩明快。`
   - **真人写实**：`电影剧照质感，真人写实，干净高清，焦点清晰，皮肤有真实纹理。`
4. **改已生成的图一律新开卡**：已有生成结果的节点改图默认新开卡并自动继承原参考图（放在旧图旁边供对比抽卡）；仅未生成的草稿才原地修改。用户说“改”或“出卡”时，先给卡片，解释最多一句。
5. **合规底线**：人物用 AI 设计的原创形象，不用真人或明星照片做参考。

### 2.3 人物设定图（波次 1 · 5 条规矩 + 纯正向标准模板）
- **五条规矩**：
  1. 全身、正面、纯白无缝影棚背景（三点式均匀柔光），双臂自然垂于身体两侧，掌心空置自然舒展，神情平静克制。
  2. **一定要写鞋子与头顶发式！** 必须正向写清鞋子款式颜色（防裁成半身）与发丝自然露出的头顶状态。
  3. 写清年龄、身高、体型、脸型、眼睛、发型、发色、服装（从上到下，写清颜色、材质和长度）、鞋子，且与故事年代严丝合缝。
  4. 成年角色约 **8 头身**，比例修长协调。
  5. 换装（`CH01-B`）属波次 2，等 `CH01-A` 出图后在 `refs` 中引用 `CH01-A` 的 `@图n` 派生。
- **人物设定图标准模板（纯正向视觉描写，画幅按项目约定或 `9:16`）**：
  ```text
  {画风句}全身正面角色设定图，纯白无缝影棚背景，干净统一的摄影棚三点式柔光。{年龄}岁{性别}，{身份}。{脸型、眼睛、眉毛、鼻子、嘴唇、肤色}。{发型、发色、长度，头顶发丝自然清晰}。身高约 {X} 厘米，{体型}，8 头身修长比例。身穿{上衣颜色材质款式}，搭配{下装颜色材质长度}，脚穿{鞋子颜色材质款式，完整露出双脚与鞋底}。双臂自然垂于身体两侧，双手掌心空置自然舒展，神情平静内敛，正视镜头。
  ```

### 2.4 【核心锁脸神器】角色身份板提示词（波次 2 · 人物全身图定稿后带 `refs` 生成）
等波次 1 的人物全身图（如 `@图1`）生成确认后，在 `canvas.image.add` 中设置 `refs: "@图1"`（横版 `16:9` 为左立绘+右三视图，竖版 `9:16` 为上特写+下三视图）：
- **16:9 横版角色身份板（`size: "16:9"`）**：
```text
基于参考图角色制作 16:9 横版角色设定身份板，纯白无缝背景。画面左侧为正面全身立绘与面部特写，右侧并排展示同一角色的侧面全身与背面全身三视图，各视角留有清晰白边间距，从头顶发丝到脚底鞋面完整呈现。
```
- **9:16 竖版角色身份板（`size: "9:16"`）**：
```text
基于参考图角色制作 9:16 竖版角色设定身份板，纯白无缝背景。画面上半部分为人物面部特写，下半部分并排展示同一角色的正面、侧面、背面全身三视图，各视角留有清晰白边间距，从头顶发丝到脚底鞋面完整呈现。
```

### 2.5 场景设定图与「正反打防镜像黄金公式」（波次 1 正打 ➔ 波次 2 反打）
- **核心原理（为什么普通反打会被模型水平镜像翻转）**：
  1. 在提示词里写“禁止水平翻转、不是镜像、绕中心旋转180度”会直接激活图像模型的“翻转”注意力；
  2. 在反打提示词里再次点名正打里的主体标志物（如油罐车、加油站破窗站房），模型为了同时保留这些物体并左右对调，必然直接把参考图做 2D 水平翻转；
  3. 正打若为逆光（太阳在画面背景里），反打转 180° 后太阳一定在**镜头正后方画外（顺光）**，天空中绝不可能再看见太阳圆球。
- **正反打三步标准流程（100% 沿用实测跑通方案）**：
  1. **拆景先定「正反两面空间布局」**：明确「正打面 A 标志物」与「反打面 B 标志物（机位原地转180°看到的对面空间，绝不与正打主体标志物重复）」。
  2. **波次 1 先出 `S01-正打`**（无参考图，拍正打面 A 标志物与主光源）。
  3. **波次 2 出 `S02-反打`（必须带 `refs: "@正打图n"` 锁死材质与色温）**：提示词严格执行 **「10% 边缘前景遮挡锚点 + 90% 对面全新景物（只字不提正打主体建筑/车辆） + 镜头后方画外反转顺光」** 三要素公式；若下游用的是支持多镜头的视频模型（如 Seedance 2.5），也可在一段视频提示词内直接按「双人定场 ➔ 过肩正打 ➔ 过肩反打」连续生成并锁死 180° 轴线与视线方向。
- **正打场景图模板（波次 1 · 无参考图）**：
  ```text
  {画风句}{公共地面材质与光线句}空旷寂静的纯环境空镜。{正打面主体建筑/车辆陈设、远景与光源位置，如：左侧破败加油站站房与生锈加油棚，右侧停放锈蚀油罐车，低垂夕阳在油罐车后方地平线形成逆光剪影，地面为龟裂干涸泥土}。
  ```
- **反打场景图标准模板（波次 2 · 实测破局版，必填三要素：边缘前景遮挡 + 对面全新空间 + 镜头后方画外顺光）**：
  ```text
  摄影机站在{正打建筑边缘，如破旧加油棚下方}朝外面的{对面空间，如荒漠公路}拍摄，画面左侧边缘是{10%同空间前景遮挡，如半根模糊的生锈加油棚铁柱}作前景遮挡，画面中央与远处是{90%对面全新景物，如开阔荒凉的废土沥青公路、倾倒的生锈路牌与绵延到天边的戈壁荒山}。{反转光源：如夕阳在镜头后方画外，金黄色的傍晚斜阳顺光照亮路面裂纹与枯草，长影投向远方公路，天空是干净的暗橙色暮光}。
  ```

### 2.6 道具设定图（波次 1 · 默认 `size: "1:1"` + 尺寸锚定纯正向模板）
- **两条规矩**：① 默认使用 `1:1` 方图，纯白无缝影棚背景，画面纯粹聚焦单件物品；② **必须写清实际厘米尺寸与外观比例质感**。
- **道具图标准模板（`size: "1:1"`）**：
  ```text
  {画风句}1:1 构图，单件道具静物特写设定图，纯白无缝影棚背景，柔和均匀的影棚轮廓光。画面中央独立呈现{物件名称、颜色、材质、表面磨损或光泽细节}，物件实际尺寸约 {X} 厘米（成年人单手可握持比例），斜俯视 45 度角清晰展示立体结构与材质肌理。
  ```

### 2.7 出图后 4 项自检

- [ ] 场景图里有没有混进人？放大看墙面、地面有没有乱纹、乱码文字？
- [ ] 道具图写清实际尺寸了吗？
- [ ] 所有人物、场景、道具图是不是严格统一在同一种画风下？
